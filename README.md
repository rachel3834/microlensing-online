# microlensing-online
Software behind the original Microlensing-online website

[Microlensing Source](https://www.microlensing-source.org/) is a public education website that 
explores the field of gravitational microlensing in depth.  

This repository contains the original verison of this website, a Django-based database.  
This repo is now closed, and the site has been fully revamped.  
The new site is developed around Github Pages, and you can find the [new repository here](https://github.com/rachel3834/microlensing_source).
